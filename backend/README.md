# Backend

This folder contains the backend code for the Canada personal investment, tax, and credit tracking system.

## Function

The backend is responsible for application APIs, data processing, business rules, and integrations needed to support personal investment, tax, and credit tracking. It should provide clear and reliable services for the website frontend and future client ends.

## Design

The backend is powered by .NET Core and hosted on Azure. Code in this folder should follow .NET Core conventions, keep API contracts clear, and keep hosting or deployment settings configurable. Financial, tax, and credit-related logic should be written in a way that is easy to review, test, and audit.
